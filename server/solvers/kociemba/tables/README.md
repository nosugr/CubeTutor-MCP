# Kociemba 求解表

这个目录保存 `RubikTwoPhase` 为 Kociemba 两阶段求解算法生成的查找表和剪枝表。

## 说明

- 这些二进制文件是运行时缓存，不是 CubeTutor 的业务源码。
- 当前完整缓存约为 70 MB，首次生成可能需要较长时间。
- 除本说明文件外，目录内容已被 Git 忽略，不会上传到仓库。
- 不要手动修改表文件，否则求解结果可能不正确。

## 

删除表文件不会破坏项目源码，但下一次调用 Kociemba 求解器时会自动重新生成，首次求解会因此明显变慢。

缓存目录由 `cubetutor/solvers/kociemba_solver.py` 显式配置，避免依赖第三方库默认且含义不清晰的 `twophase/` 目录名。
