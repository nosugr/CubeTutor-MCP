## 1. 目标与设计定位

基于开源 [cuber](https://github.com/huazhechen/cuber) 3D 渲染引擎，在浏览器内呈现**高质感、轻快明亮、透视自然且交互丝滑**的三阶魔方数字孪生：
- **视觉品质**：浅色通透背景、圆润倒角黑色塑料骨架、内嵌圆角半哑光贴纸、真实光影与高光反射，视觉效果完全对齐 cuber 官方标准。
- **构图视角**：默认采用标准的 **3/4 黄金等轴测教学视角**（顶面、正面、侧面比例均衡），透视自然不畸变。
- **交互手感**：视角拖拽阻尼平滑，支持双击/快捷键平滑复位至最佳观察角；键盘快捷键及步序执行层转平顺流畅。
- **契约稳定**：对外严格保持 `setFacelets` / `getFacelets` / `playMove` 54 格状态契约，与后端及上层业务解耦。

## 2. 架构与分工

```text
web/js/main.js · keyboard.js · player.js · capture.js
        │  调用 createCube3D(container)
        ▼
web/js/cube3d.js                 # 适配层：对外 API、相机/控制器配置、光影与渲染循环
        │
        ├─ setFacelets / getFacelets  ↔  54 格状态双向转换（reset + stick / serialize）
        ├─ playMove / setSpeed / isBusy  ↔  Twister 动画队列 + 锁状态监听
        └─ 渲染循环与视角控制         ↔  World.scene / camera + OrbitControls + 黄金视角
                │
                ▼
web/vendor/cuber/                # 3D 渲染引擎核心（MIT）
  world.ts/js · cube · cubelet · twister · tweener · define …
```

* **`vendor/cuber`**：提供倒角几何体（`Frame`）、圆角贴纸（`Sticker`）、层转动画（`Twister`）与基础材质定义。
* **`cube3d.js`（适配层）**：负责挂载画布、环境光效与渲染器配置、黄金视角初始化、视角复位交互、Promise 化单步执行与 54-facelet 契约保证。

## 3. 视觉与光影系统规范

### 3.1 浅色环境与背景
- **背景设计**：采用柔和明亮的浅色微渐变（Soft Radiant Light Mesh Gradient），从淡蓝灰（`#e8f0f8`）到微白（`#f4f7fb`），衬托魔方立体感。
- **渲染器配置**：启用 `antialias: true`、`outputColorSpace = THREE.SRGBColorSpace`、`alpha: true`。

### 3.2 材质与配色规范（对齐 cuber 标准色盘）
* **塑料骨架（Core）**：深炭黑哑光材质（`#17181C`），配合细腻的 Specular 高光（`#8A94A6`，shininess: 2~4），呈现真实塑料质感。
* **标准贴纸配色**：
  * **U（顶面）**：`#F7FAFC`（柔和纯净白）
  * **D（底面）**：`#FFD84D`（明亮暖黄）
  * **F（正面）**：`#18A35D`（翠绿）
  * **B（背面）**：`#2F6FEB`（宝蓝）
  * **L（左面）**：`#FF8A2A`（活力亮橙）
  * **R（右面）**：`#E6483D`（鲜活正红）
* **自发光与光照平衡**：贴纸材质使用 `MeshLambertMaterial`，配合合理的环境光（`AmbientLight` 强度约 0.85~0.95）与斜上方主光源（`DirectionalLight` 强度约 0.3~0.4），保证六面在任何角度均层次分明、不泛白、不发灰。

---

## 4. 视角与相机控制规范

### 4.1 黄金初始观察视角
- **默认视场角（FOV）**：约 45° ~ 50°，消除过近导致的广角透视形变。
- **默认相机角度**：采用经典 3/4 俯视偏右视线（Euler: 仰角约 25°~30°，水平角约 -35°~-40°），使顶面（U）、正面（F）、右面（R）以黄金比例同时清晰可见。

### 4.2 交互与控制增强
- **OrbitControls 优化**：开启平滑阻尼（`enableDamping = true`，`dampingFactor = 0.05`），禁止平移（`enablePan = false`），缩放距离限制在安全区间（`minDistance` / `maxDistance`），防止穿模或拉伸过远。
- **双击平滑复位**：支持双击 3D 视图空白区域平滑过渡插值复位至默认黄金视角。

## 5. 对外 API 契约（保持稳定）

`createCube3D(container)` 返回对象契约：

| 方法 | 说明 |
|------|------|
| `setFacelets(str)` | 传入 54 位 facelet 字符串，立即打断动画并重置贴纸颜色与内部状态一致 |
| `getFacelets()` | 序列化返回当前 54 位 facelet 字符串（与 Kociemba `URFDLB` 顺序 1:1） |
| `playMove(move)` | 返回 `Promise`，执行指定单步公式（如 `R`, `U'`, `F2`），动画完成后 resolve |
| `setSpeed(speed)` | 设置动画播放速度倍率（0.25x ~ 3x） |
| `isBusy()` | 当前是否有层转动画正在进行 |
| `resetView()` | 平滑复位至默认 3/4 黄金教学观察视角 |

---

## 6. 验收标准

1. **视觉一致性**：在浅色背景下呈现精致现代的 3D 魔方，黑框圆角与六色贴纸质感高度对齐 cuber 官方效果（图 1）。
2. **构图自然**：初始视角比例协调，无过度透视畸变，顶/正/右三面清晰可辨。
3. **交互丝滑**：旋转与缩放手感阻尼舒适，双击空白处可平滑复位视角。
4. **单步与排队**：键盘拧层及连续步序播放流畅，不卡顿、不错位、无穿模。
5. **契约恒等**：`setFacelets(SOLVED)` ↔ `getFacelets() === SOLVED`，打乱与还原过程中的前后端状态 100% 保持一致。

## 7. 明确不做（当前模块边界）

- 手势直接在 3D 魔方表面划动切层（容易与全视角拖拽冲突，且易导致与会话状态脱节；旋转只走视角控制，转层走键盘与步序播放器）；
- 引入无关的 Vue/React 外部框架或多阶魔方。
