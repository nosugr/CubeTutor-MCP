## 一、 项目定位与契约

基于 MCP 的 3D 智能魔方教学平台：
- **前端架构**：React 19 + TypeScript + Vite + Three.js 3D 魔方物理引擎（`src/cuber`）+ 摄像头实时扫面（`src/cv/scanner.ts`）；
- **后端大脑**：Python FastAPI 后端（共享会话状态 / 三大求解引擎 / 真实 MCP Server / Agent 调度 / TTS 语音流 / YOLOv8 视觉检测）；
- **唯一状态真相**：Kociemba 54 格 facelet 字符串（`URFDLB` 序列，`SOLVED = U*9 R*9 F*9 D*9 L*9 B*9`）。

## 三、 已完成核心工作回顾 (截至 2026-08-25)

1. **全栈架构整合与统一**：
   - 将 React 19 前端与 Python FastAPI 后端全量合并至 `CubeTutor` 统一工程中；
   - 配置全栈 `.gitignore` 与 `package.json`，清理冗余作者历史信息与无用模板文件。
2. **后端引擎深度重构**：
   - 求解器分包重构：拆分为 `server/solvers/beginner/`（7阶段教学）、`server/solvers/cfop/`（4阶段速拧）与 `server/solvers/kociemba/`（含 `tables/` 预计算表）；
   - 视觉识别模块化：建立 `server/cv/` 专有包（YOLOv8 检测、OpenCV 色彩空间自适应提取、模型训练脚本）；
   - 目录扁平化：精简去除 `cubetutor/` 冗余中间层，代码内 import 语句全量规范化；
   - 自动化测试套件：**39 项 pytest 单元测试持续 100% 全部通过**。
3. **单窗口一键极速启动 (start.bat)**：
   - 基于 `concurrently` 实现单终端窗口同时并发拉起前后端服务，输出彩色分类日志，自动唤起浏览器并支持 `Ctrl+C` 一键退出。
4. **文档体系与 Git 仓库管理**：
   - 编写了极简、专业的 GitHub 开源规范主文档 `README.md` 与原版演示手册 `docs/screenshot/demo.md`；
   - 本地 Git 仓库重命名为 `main` 分支并成功对齐推送至远程仓库：`https://github.com/nosugr/CubeTutor-MCP`。

## 四、 运行与验证指令

```powershell
# 1. 一键启动前后端（单终端窗口并发，推荐）
.\start.bat

# 2. 手动启动前端开发服务器 (React 19 + Vite :5173)
npm run dev

# 3. 手动启动 Python 核心后端 (FastAPI + MCP + 求解引擎 :8000)
uvicorn --app-dir server api.http_app:app --port 8000 --host 127.0.0.1

# 4. 运行测试套件（提交底线：39 个测试全绿）
pytest server/tests
```

## 六、 模块启动协作流程

后续每个模块启动时遵循以下标准流程：
1. **需求讨论**：先就该模块的交互形式、视觉效果或文案内容与用户展开讨论，达成共识；
2. **编写设计规范（Spec）**：在 `docs/superpowers/specs/` 下形成专项设计稿，经用户批准；
3. **编写实施计划（Plan）**：在 `docs/superpowers/plans/` 下拆分可打勾的施工步骤；
4. **编码与点验**：按计划执行，改完后运行 `pytest` 及前端浏览器功能点验；
5. **更新看板**：回写计划勾选与本进展书状态。
