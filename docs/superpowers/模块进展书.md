## 一、 项目定位与契约

基于 MCP 的 3D 智能魔方教学平台：
- **前端架构**：React 19 + TypeScript + Vite + Three.js 3D 魔方物理引擎（`src/cuber`）+ 摄像头实时扫面（`src/cv/scanner.ts`）+ Emotion Ball 情绪球 Avatar 伴学系统；
- **后端大脑**：Python FastAPI 后端（共享会话状态 / 三大求解引擎 / 真实 MCP Server / Agent 调度 / 动态 24 姿态中心归一化 / YOLOv8 视觉检测）；
- **唯一状态真相**：Kociemba 54 格 facelet 字符串（`URFDLB` 序列，`SOLVED = U*9 R*9 F*9 D*9 L*9 B*9`）。

## 三、 已完成核心工作回顾 (截至 2026-08-25)

1. **AI 伴学交互面板与 Emotion Ball 头像集成**：
   - 打造右侧抽屉式「魔方助手」交互面板，支持自由拖动左侧边框改变面板宽度，支持在左侧 3D 区域右键快速收起；
   - 本地持久化保存最新 60 条历史对话（`localStorage`），页面刷新记录不丢失；
   - 接入 **Emotion Ball 情绪球 32 套表情物理引擎**，实现视线跟随、撒花（`33` 号任务完成）、好奇大圆眼（`03` 号思考中）与警示报警（`34` 号报错）；
   - 提供专业的大模型配置中心（支持 DeepSeek、通义千问、OpenRouter、OpenAI、硅基流动、Moonshot、Ollama 等，内置一键检测模型列表与连接测试）。
2. **儿童益智与初学者大白话教学转换**：
   - 统一以 6 处固定中心块颜色（顶白 U、底黄 D、正绿 F、背蓝 B、左橙 L、右红 R）为基准坐标系；
   - 将专业 WCA 转动代号（如 `R U R' U'`）100% 翻译为“大白话动作 + 颜色方位”（如：“右侧红色面向上推一步 `R`，顶层白色面向左拨一步 `U`”）；
   - 后端增加 `format_cube_layout_cn` 算法，将魔方 54 格实时状态预处理为按 6 大中心块颜色索引的 3x3 真实分布，彻底解决大模型混淆颜色中心面问题。
3. **空间旋转群动态中心归一化（Dynamic Center Normalization）**：
   - 算法层适配三维空间旋转群 $SO(3)$ 对应的 **24 种合法空间物理朝向**；
   - 用户在 3D 舞台中无论如何整体翻转魔方视角，求解器均能动态识别中心块朝向并瞬间归一化，彻底根除翻转魔方后的 `centers` 校验报错。
4. **原生 Web Speech API 智能语音伴读（TTS）**：
   - 采用浏览器原生 `window.speechSynthesis` 引擎，中文语调亲切自然；
   - 文本清洗算法自动剔除 Markdown 语法符号；
   - 默认静音保护，每条回答气泡附带独立语音播放按钮，支持随点随播与声波跳动动效。
5. **主流 Agent 风格的 MCP 4 阶段聚合调用轨迹**：
   - 将 `get_cube_state`、`validate_state`、`get_solution` 及多步 `apply_move` 自动聚合为 4 个核心交互阶段，提供清晰的折叠下拉查看体验。
6. **键盘事件精准隔离与代码洁净度治理**：
   - 在对话框与设置面板打字输入时彻底拦截物理键盘冒泡，杜绝输入时误触 3D 魔方旋转；
   - 全量消除未使用的无用变量与 `any` 类型，IDE 保持 **0 告警 / 0 错误**；
   - **41 项 pytest 单元与端到端测试 100% 全部通过**。

## 四、 运行与验证指令

```powershell
# 1. 一键启动前后端（单终端窗口并发，推荐）
.\start.bat

# 2. 手动启动前端开发服务器 (React 19 + Vite :5173)
npm run dev

# 3. 手动启动 Python 核心后端 (FastAPI + MCP + 求解引擎 :8000)
uvicorn --app-dir server api.http_app:app --port 8000 --host 127.0.0.1

# 4. 运行全量测试套件（提交底线：41 个测试全绿）
pytest server/tests

# 5. 前端 TypeScript 严格类型检查
npx tsc --noEmit
```
